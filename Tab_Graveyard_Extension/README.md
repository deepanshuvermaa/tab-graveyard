# Tab Graveyard Chrome Extension

Never lose a closed tab again! Tab Graveyard keeps a history of all tabs you close, allowing you to restore them at any time.

## Features

- **Tab History**: Automatically tracks all tabs you close
- **Quick Restore**: Click any closed tab to restore it
- **Search**: Find closed tabs by title or URL
- **Settings**: Customize how many tabs to keep in history
- **Clean UI**: Simple, elegant interface

## Installation

1. Download the Tab_Graveyard_Extension.zip file
2. Extract it to a folder
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode" (top right corner)
5. Click "Load unpacked" and select the extracted folder
6. Done! The extension is now active

## Usage

- **View closed tabs**: Click the extension icon in Chrome toolbar
- **Restore a tab**: Click on any tab in the list
- **Delete a tab**: Click the X button on the right
- **Search tabs**: Use the search box to find specific tabs
- **Settings**: Click the gear icon to configure options
