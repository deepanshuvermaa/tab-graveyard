# Deployment — Tab Graveyard

## Chrome Extension (Install Locally)
1. Open `chrome://extensions`
2. Enable "Developer mode" (top-right)
3. Click "Load unpacked" → select `Tab_Graveyard_Extension` folder
4. Done. Extension icon appears in toolbar.

## Chrome Web Store (Public Distribution)
1. Zip the `Tab_Graveyard_Extension` folder
2. Go to https://chrome.developer.google.com/
3. Pay one-time $5 developer fee
4. Upload ZIP, fill listing, submit for review (1-3 days)

## Landing Page → GitHub Pages (Free)
1. Create a GitHub repo (e.g., `tab-graveyard`)
2. Push `index.html` to the `main` branch
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Live at `https://yourusername.github.io/tab-graveyard/`

## Landing Page → cPanel
Upload `index.html` to `public_html/tab-graveyard/` via File Manager.
